# AutoStudy 처음 설정하기

> 이 문서는 **VS Code나 터미널을 사용해 본 적이 없는 Windows 사용자**를 위한 최초 1회 설정 안내입니다. 설정이 끝난 뒤에는 [`사용법.md`](./사용법.md)만 따라 하면 됩니다.

## 설정을 시작하기 전에

AutoStudy는 한 컴퓨터의 Google Drive 동기화 폴더를 작업 공간으로 사용합니다. 이 폴더를 코드에서는 `WATCH_PATH`라고 부릅니다. 프로그램 폴더 자체와 작업 폴더는 다른 위치여야 합니다. 예를 들어 프로그램은 `문서\AutoStudy`에, 작업 폴더는 Google Drive 안의 `내 드라이브\AutoStudy`에 둘 수 있습니다.

| 준비물 | 왜 필요한가요? | 준비 상태 |
|---|---|---|
| Windows 10 또는 11 PC | 현재 프로그램은 Windows 경로와 라이브러리를 기준으로 제작되었습니다. | 필수 |
| 안정적인 인터넷 | Gemini, Google Drive, Notion에 연결합니다. | 필수 |
| Google 계정 | Drive 동기화, Colab, Gemini API, Drive OAuth 인증에 사용합니다. | 필수 |
| Notion 계정 | 강의 요약과 슬라이드 스크립트를 저장합니다. | 필수 |
| 관리자 권한 또는 프로그램 설치 권한 | Python·Google Drive·필요 패키지를 설치합니다. | 권장 |

> **보안 원칙:** Gemini API 키·Notion 토큰·`credentials.json`·`token.pickle`은 다른 사람에게 공유하지 마세요. AutoStudy 폴더를 압축해 전달할 때도 이 파일들은 제외해야 합니다.[1]

## 1. 프로그램 폴더 준비

압축 파일의 압축을 풉니다. 폴더 이름은 바꾸어도 되지만, **프로그램 폴더 내부의 파일 이름과 폴더 구조는 바꾸거나 이동하지 마세요.** 초보 사용자는 `chobo` 폴더 안의 파일만 열면 됩니다. `main.py`와 `colab` 폴더는 한 단계 위의 프로그램 폴더에 있어야 하며, `chobo` 안의 실행 파일이 자동으로 해당 위치를 찾아 실행합니다.

프로그램 폴더는 `다운로드`처럼 파일이 자주 정리되는 곳보다 `문서\AutoStudy`처럼 고정된 위치가 좋습니다. 아래 표의 예시에서 `C:\Users\학생이름\Documents\AutoStudy`가 프로그램 폴더입니다.

| 구분 | 권장 위치 예시 | 넣는 것 |
|---|---|---|
| 프로그램 폴더 | `C:\Users\학생이름\Documents\AutoStudy` | AutoStudy 코드와 실행 파일 |
| 작업 폴더(`WATCH_PATH`) | `G:\내 드라이브\AutoStudy` | 강의록, 녹음, 전사문, 결과물 |

## 2. Google Drive 작업 폴더 만들기

Google Drive for desktop을 설치하고, 강의 자료를 동기화할 Google 계정으로 로그인합니다. 파일 탐색기에서 **Google Drive** 또는 **내 드라이브**가 보이는지 확인하세요. 그 안에 `AutoStudy`라는 새 폴더를 만듭니다. 이 폴더가 `WATCH_PATH`입니다.

설정 프로그램은 이 폴더 안에 아래 두 폴더를 자동으로 만듭니다. 이미 폴더를 만들었다면 그대로 선택하면 됩니다.

```text
AutoStudy 작업 폴더
├── lecture     ← 줄필기·야붙 PDF를 넣는 곳
└── merged      ← 하루치 복습 PDF 합본이 저장되는 곳
```

**중요한 것은 실제 경로입니다.** 파일 탐색기의 주소 표시줄을 눌렀을 때 보이는 경로가 `G:\내 드라이브\AutoStudy`라면, 이 경로 전체를 설정 화면에서 선택합니다. `lecture` 폴더를 선택하는 것이 아니라 그보다 한 단계 위인 `AutoStudy` 작업 폴더를 선택해야 합니다.

## 선택 설치: 해당하는 경우에만

아래 두 프로그램은 모든 사용자가 설치할 필요가 없습니다. **일반 PDF와 Google Colab 전사만 사용한다면 이 절은 건너뛰어도 됩니다.**

| 프로그램 | 설치가 필요한 경우 | 설치 후 확인 |
|---|---|---|
| Tesseract OCR | 글자가 선택되지 않는 이미지형·스캔 PDF를 사용할 때 | `tesseract --version`과 `tesseract --list-langs`를 실행해 `kor`, `eng`가 모두 보이는지 확인 |
| ffmpeg | YouTube 다운로드 또는 영상 병합 기능을 사용할 때 | `ffmpeg -version`을 실행해 버전 정보가 보이는지 확인 |

### 스캔한 PDF, 혹은 사진만 있는 페이지가 존재한다면: Tesseract OCR

Tesseract OCR을 설치하고 한국어(`kor`)·영어(`eng`) 언어 데이터를 추가하세요. Tesseract 버전이 표시되어도 언어 목록에 `kor`가 없으면 한국어 스캔 PDF는 읽을 수 없습니다.

```bat
tesseract --version
tesseract --list-langs
```

### YouTube 다운로드 또는 영상 병합 기능을 쓴다면: ffmpeg

ffmpeg를 설치한 뒤 아래 명령을 실행합니다. 버전 정보가 보이면 설치와 경로 등록이 완료된 것입니다.

```bat
ffmpeg -version
```

> 위 명령에서 `인식할 수 없는 명령` 또는 `not recognized` 오류가 나오면 프로그램이 설치되지 않았거나 PATH 등록이 되지 않은 상태입니다. 설치 뒤에는 VS Code나 명령 프롬프트 창을 완전히 닫았다가 다시 여세요.

## 3. Gemini API 키 만들기

AutoStudy는 PDF의 의학용어 추출, 전사문 교정, 시험 대비 요약, Anki 카드 생성에 Gemini API를 사용합니다. Google AI Studio의 API 키 관리 페이지에서 Google 계정으로 로그인한 뒤 **Create API key**를 선택해 키를 만들고, 표시되는 문자열 전체를 복사합니다. 새로 만든 키는 Gemini API 인증에 사용되며, Google은 이를 비밀번호처럼 취급하고 비공개로 보관할 것을 안내합니다.[1]

| 해야 할 일 | 확인 방법 |
|---|---|
| [Google AI Studio API Keys](https://aistudio.google.com/app/apikey)에서 키 생성 | 영문·숫자 등이 긴 한 줄의 키가 보입니다. |
| 키 전체 복사 | 앞뒤 공백이나 따옴표 없이 복사합니다. |
| 키를 메신저·문서·코드에 올리지 않기 | AutoStudy 설정 화면에만 붙여 넣습니다. |
| 키가 유출되었다고 의심되면 새 키 생성 후 기존 키 폐기 | 키를 바꾼 뒤 `설정_변경하기.cmd`에서 새 키를 다시 저장합니다. |

> 이 프로젝트가 읽는 변수 이름은 공식 예시의 `GEMINI_API_KEY`가 아니라 **`API_KEY`**입니다. 이는 AutoStudy 코드의 현재 구현에 맞춘 이름이며, 설정 프로그램이 자동으로 올바른 `.env` 파일을 만듭니다.

## 4. Notion 데이터베이스와 토큰 준비

AutoStudy는 결과 페이지를 만들기 위해 Notion의 **전체 페이지 데이터베이스** 하나가 필요합니다. 새 데이터베이스를 만들고 속성 이름과 선택값을 아래 표와 **완전히 동일하게** 설정하세요. 코드가 이 한글 이름을 그대로 사용합니다.

| 속성 이름 | 속성 종류 | 필요한 값 또는 설정 |
|---|---|---|
| `이름` | 제목(Title) | 기본 제목 속성의 이름을 `이름`으로 변경합니다. |
| `원본 PDF` | URL | AutoStudy가 원본 PDF Drive 링크를 넣습니다. |
| `상태` | 선택(Select) | 선택값으로 `✅ 완료`를 추가합니다. |

그다음 [Notion Developer Portal](https://www.notion.so/developers/tokens)에서 **Personal Access Token**을 새로 만들고 복사합니다. Notion은 토큰을 다시 보여 주지 않을 수 있으므로 안전한 곳에 보관해야 합니다.[2]

데이터베이스를 전체 페이지로 연 뒤 오른쪽 위 **공유(Share)** 메뉴에서 생성한 Notion 연결을 추가해야 합니다. 연결에 공유하지 않으면 AutoStudy가 페이지를 만들 수 없습니다. Notion은 데이터베이스 링크에 포함된 32자 또는 36자 문자열을 데이터베이스 ID로 사용하며, 하이픈이 있어도 됩니다.[3]

| 설정값 | 얻는 위치 |
|---|---|
| `NOTION_TOKEN` | Notion Developer Portal에서 방금 복사한 Personal Access Token |
| `NOTION_DATABASE_ID` | 데이터베이스를 전체 페이지로 열기 → 공유 → 링크 복사 → URL의 긴 ID 부분 |
| `NOTION_DATA_SOURCE_ID` | 데이터베이스 오른쪽 위 `•••` → **Manage data sources** → **Copy data source ID** |

> **Notion에서 데이터베이스 ID와 데이터 소스 ID는 서로 다릅니다.** 둘 중 하나를 다른 칸에 넣으면 Anki 링크를 추가하는 단계가 실패합니다.[3]

## 5. Google Drive 연결용 `credentials.json` 준비

Notion 결과 페이지에는 Google Drive에 동기화된 PDF와 Anki 파일의 링크가 들어갑니다. 이를 위해 프로젝트의 프로그램 폴더에 **Google Drive OAuth 데스크톱 앱**용 `credentials.json` 파일이 필요합니다.

Google Cloud Console에서 사용할 프로젝트를 연 뒤 Google Drive API를 사용 설정하고, Google Auth Platform의 Clients에서 **Desktop app** 유형 OAuth 클라이언트를 만들어 JSON을 다운로드합니다. 다운로드한 파일의 이름을 정확히 `credentials.json`으로 바꾸어, `main.py`와 같은 프로그램 폴더에 넣습니다. Google은 사용자 Drive 데이터에 동의하여 접근할 때 OAuth 클라이언트 ID가 필요하다고 안내합니다.[4]

```text
프로그램 폴더
├── main.py
├── credentials.json      ← 설정 도우미가 여기에 복사합니다
├── colab/
└── chobo/
    ├── 설정_변경하기.cmd
    ├── AutoStudy_실행.cmd
    └── 처음_설정하기.py
```

처음으로 강의의 두 번째 실행을 할 때 브라우저가 열리면, **작업 폴더를 동기화하는 것과 같은 Google 계정**으로 로그인하여 권한 요청을 승인하세요. 인증이 끝나면 같은 프로그램 폴더에 `token.pickle`이 생기며, 다음부터는 보통 다시 로그인하지 않습니다. `credentials.json`과 `token.pickle`은 계정 접근 정보이므로 절대로 공유하지 마세요.

## 6. 설치와 설정 화면 실행

이제 `chobo` 폴더의 `설치하기.cmd`를 더블클릭합니다. 검은 창이 열려 Python과 필요한 라이브러리를 준비합니다. 처음 실행은 다운로드 용량 때문에 시간이 걸릴 수 있으며, 창이 자동으로 닫히기 전까지 기다리세요.

설치가 끝나면 같은 `chobo` 폴더의 `설정_변경하기.cmd`를 더블클릭합니다. 설정 창에서 다음 값을 입력하거나 선택한 뒤 **저장하기**를 누르세요.

| 화면 항목 | 입력할 내용 |
|---|---|
| 작업 폴더(`WATCH_PATH`) | 2단계에서 만든 Google Drive 안의 `AutoStudy` 폴더 |
| Gemini API 키(`API_KEY`) | 3단계에서 복사한 키 전체 |
| Notion 토큰 | 4단계에서 만든 Personal Access Token |
| Notion 데이터베이스 ID | 데이터베이스 링크에서 복사한 ID |
| Notion 데이터 소스 ID | Manage data sources에서 복사한 ID |
| `credentials.json` | 5단계에서 받은 파일을 찾아 선택 |

저장에 성공하면 프로그램 폴더 안에 `.env` 파일이 만들어지고, 작업 폴더 안에는 `lecture`, `merged` 폴더가 준비됩니다. `.env`는 직접 열거나 다른 사람에게 보낼 필요가 없습니다.

## 7. 최초 설정 확인

설정 직후 `chobo` 폴더의 `AutoStudy_실행.cmd`를 더블클릭합니다. 아직 강의 파일이 없다면 `초기 스캔 완료`라는 문구가 보이면 정상입니다. 강의 자료가 들어 있다면 실제 처리가 시작될 수 있으므로, 처음 점검은 빈 작업 폴더에서 하는 편이 안전합니다.

| 확인 항목 | 정상 상태 |
|---|---|
| `.env` | 프로그램 폴더에 존재하며, 내용은 공개하지 않습니다. |
| `credentials.json` | 프로그램 폴더에 존재합니다. |
| `WATCH_PATH` | 선택한 Google Drive 작업 폴더입니다. |
| `lecture`, `merged` | 작업 폴더 바로 아래에 존재합니다. |
| 실행 창 | `초기 스캔 완료` 또는 처리 진행 문구가 표시됩니다. |

## 자주 막히는 설정 문제

| 증상 | 먼저 확인할 것 |
|---|---|
| `Python을 찾을 수 없습니다`가 나옵니다. | [Python 공식 다운로드 페이지](https://www.python.org/downloads/windows/)에서 Python 3.11을 설치할 때 **Add python.exe to PATH**를 체크한 뒤 `설치하기.cmd`를 다시 실행합니다. |
| `API_KEY 환경변수가 설정되지 않았습니다`가 나옵니다. | `chobo` 폴더의 `설정_변경하기.cmd`를 열어 Gemini API 키를 다시 붙여 넣고 저장합니다. |
| `WATCH_PATH` 관련 오류 또는 `lecture` 폴더 오류가 납니다. | Drive 안의 작업 폴더를 선택했는지, `lecture` 자체가 아닌 그 상위 작업 폴더를 선택했는지 확인합니다. |
| Notion 업로드가 실패합니다. | 데이터베이스에 `이름`, `원본 PDF`, `상태` 속성이 정확히 있는지와 Notion 연결 공유 여부를 확인합니다. |
| Drive 로그인 창이 반복해서 나옵니다. | `credentials.json`이 프로그램 폴더에 있는지, 로그인 계정이 작업 폴더의 Drive 계정과 같은지 확인합니다. |
| 스캔 PDF 글자가 읽히지 않습니다. | Tesseract OCR과 한국어·영어 언어 데이터를 설치한 뒤 다시 시도합니다. |
