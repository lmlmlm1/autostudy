# AutoStudy 사용법

> 이 문서는 [`처음_설정하기.md`](./처음_설정하기.md)를 이미 완료한 사용자를 위한 **매일의 강의 처리 안내**입니다. 명령어를 직접 입력하지 말고, 안내된 `.cmd` 파일을 더블클릭하세요.

## 처리 전에 준비할 것

강의마다 PDF와 녹음 파일의 **앞 이름(base name)** 을 똑같이 맞춰야 합니다. 가장 안전한 형식은 `월일_교시`입니다. 예를 들어 1월 23일 1교시는 `0123_1`로 통일합니다.

| 자료 | 어디에 넣나요? | 파일 이름 예시 |
|---|---|---|
| 줄필기 PDF | 작업 폴더의 `lecture` | `0123_1_줄.pdf` |
| 야붙 PDF | 작업 폴더의 `lecture` | `0123_1_야붙.pdf` |
| 야붙에 필기한 합본 PDF | 작업 폴더의 `lecture` | `0123_1_야붙필기.pdf` |
| 이미 하나로 합친 PDF | 작업 폴더의 맨 바깥 | `0123_1.pdf` |
| 녹음 파일 | 작업 폴더의 맨 바깥 | `0123_1.m4a` |

> **한 번에 한 강의만 처리하세요.** `0123_1`과 `0123_10`처럼 앞 이름이 겹치는 강의를 작업 폴더 바깥에 동시에 두면 엉뚱한 파일이 함께 이동할 수 있습니다.

작업 폴더의 기본 모양은 아래와 같습니다. 여기서 ‘작업 폴더’는 최초 설정에서 선택한 Google Drive 안의 `AutoStudy` 폴더입니다.

```text
작업 폴더
├── lecture
│   ├── 0123_1_줄.pdf
│   └── 0123_1_야붙.pdf
├── merged
└── 0123_1.m4a
```

## 강의마다 하는 네 단계

### 1단계. 자료 넣기

강의록 PDF를 `lecture` 폴더에 넣고, 녹음 파일은 작업 폴더의 맨 바깥에 넣습니다. 이미 하나로 합친 PDF라면 녹음 파일과 같은 위치에 `0123_1.pdf`처럼 넣으면 됩니다. Google Drive 동기화 아이콘이 돌아가고 있다면 동기화가 끝날 때까지 잠시 기다리세요.

### 2단계. 첫 번째 실행 — PDF 읽기와 의학용어 키워드 만들기

`chobo` 폴더의 **`AutoStudy_실행.cmd`를 더블클릭**합니다. 검은 창이 열리고 처리 메시지가 보입니다. 창이 `처리를 마쳤습니다`라는 안내와 함께 멈출 때까지 닫지 마세요.

첫 실행 뒤 작업 폴더의 맨 바깥에 아래 파일이 생기면 정상입니다.

| 생성 파일 | 의미 |
|---|---|
| `0123_1.pdf` | 줄필기·야붙을 병합한 원본 강의록 또는 준비된 원본 PDF |
| `0123_1_강의자료.txt` | PDF에서 읽어 낸 강의 텍스트 |
| `0123_1_whisperkeyword.txt` | 녹음 전사에 사용할 의학용어 키워드 |

`_whisperkeyword.txt`가 보이지 않으면 Gemini API 키 설정 또는 PDF 읽기 과정에 문제가 생긴 것입니다. 창을 캡처하고 [`처음_설정하기.md`](./처음_설정하기.md)의 문제 해결 표를 확인하세요.

### 3단계. Google Colab에서 녹음 전사하기

프로그램 폴더의 `colab` 폴더를 열어 `Transcribe.ipynb` 파일을 Google Colab에서 엽니다. 노트북을 열었다면 위에서 아래 순서대로 실행하세요. 각 실행 버튼은 해당 칸의 왼쪽에 있는 재생 모양 버튼입니다.

| 실행 순서 | Colab에서 하는 일 | 끝난 뒤 확인할 것 |
|---:|---|---|
| 1 | Google Drive 연결 칸 실행 후, 권한 요청에 동의 | Drive 연결 완료 문구 |
| 2 | 녹음이 `.mp4`이면 MP4→M4A 변환 칸 실행 | `.m4a` 파일 생성 |
| 3 | Whisper 설치 칸 실행 | 설치 완료 문구 |
| 4 | 전사 실행 칸 실행 | `_음성스크립트.txt` 생성 |

첫 실행 시 Google 로그인과 Drive 권한 허용 화면이 나옵니다. 반드시 **작업 폴더가 있는 동일한 Google 계정**으로 로그인하세요. 전사가 끝난 뒤 작업 폴더의 맨 바깥에 `0123_1_음성스크립트.txt`가 생겼는지 확인합니다.

> 전사는 `_whisperkeyword.txt`가 있는 강의만 시작합니다. 파일이 없으면 2단계를 먼저 다시 실행하세요. 이미 `_음성스크립트.txt`가 있는 파일은 중복 전사를 막기 위해 자동으로 건너뜁니다.

### 4단계. 두 번째 실행 — 교정·요약·Notion·Anki·복습 PDF 만들기

`0123_1_음성스크립트.txt`가 생긴 것을 확인한 뒤, 다시 **`AutoStudy_실행.cmd`를 더블클릭**합니다. 이번에는 Gemini가 강의록과 전사문을 함께 사용해 교정본과 요약을 만들고, Notion과 Anki, 복습 PDF를 순서대로 처리합니다.

처리 중에는 Google Drive 동기화가 완료될 때까지 기다립니다. 특히 Anki 파일 링크는 Drive에 업로드된 뒤 Notion에 덧붙여지므로, 파일 크기와 네트워크에 따라 조금 늦을 수 있습니다.

## 결과 확인하기

처리가 끝나면 작업 폴더 안에 강의 이름의 폴더가 생깁니다. 예를 들어 `0123_1` 강의는 `작업 폴더\0123_1`에서 확인합니다.

| 결과물 | 위치 | 설명 |
|---|---|---|
| 최종 교정 스크립트 | `0123_1\0123_1_최종교정본.txt` | 슬라이드 순서에 맞춘 교정 전사문 |
| 핵심 요약 | Notion 데이터베이스의 새 페이지 | 시험 대비 단권화 노트와 슬라이드별 스크립트 |
| Anki 카드 묶음 | `0123_1\0123_1_통합본.apkg` | Anki 앱에서 가져와 복습하는 카드 |
| 복습용 PDF | `0123_1\0123_1_scripted.pdf` | 요약과 슬라이드별 교정 스크립트를 합친 PDF |

Notion 업로드가 성공해야 `_result.json`이 `_done.json`으로 바뀌고 복습용 PDF가 만들어집니다. 따라서 Anki는 생겼지만 복습용 PDF가 없을 때는 Notion 속성·토큰·공유 설정을 먼저 확인하세요.

## 하루치 복습 PDF 하나로 합치기

같은 날짜 강의를 모두 처리한 뒤 `chobo` 폴더의 **`오늘_복습PDF_합치기.cmd`를 더블클릭**합니다. 검은 창이 날짜를 물으면 `0123`처럼 네 자리 날짜를 입력하고 Enter를 누르세요.

모든 강의 폴더에 개별 `_scripted.pdf`가 있어야 합본이 생성됩니다. 성공하면 아래 파일을 확인할 수 있습니다.

```text
작업 폴더\merged\0123_merged_scripted.pdf
```

## 자주 생기는 문제

| 상황 | 먼저 할 일 |
|---|---|
| `AutoStudy_실행.cmd`가 실행되지 않아요. | `chobo` 폴더의 `설치하기.cmd`를 다시 실행하고, 설정이 끝났는지 확인합니다. |
| 전사문이 생성되지 않아요. | `_whisperkeyword.txt`가 있는지, Colab의 Drive 경로가 작업 폴더와 같은지 확인합니다. |
| Notion에는 결과가 없어요. | Notion 데이터베이스 속성 이름과 연결 공유, 토큰·ID를 확인합니다. |
| Anki는 있는데 복습용 PDF가 없어요. | Notion 업로드가 성공했는지와 `_done.json`이 있는지 확인합니다. |
| 파일이 이상하게 섞였어요. | 이름 앞부분이 겹치는 강의가 동시에 있었는지 확인하고, 처리 중인 강의 외 파일은 작업 폴더 바깥으로 옮깁니다. |
| 같은 강의를 처음부터 다시 만들고 싶어요. | 결과 폴더 전체를 먼저 백업한 뒤, 원본 PDF·음성·텍스트를 작업 폴더 맨 바깥으로 되돌리고 해당 강의의 `_done.json`을 제거합니다. |

## 도움을 요청할 때

오류가 나면 `AutoStudy_실행.cmd` 창을 닫지 말고 전체 화면을 캡처하세요. 아래 네 가지를 함께 전달하면 복구가 빨라집니다.

| 전달할 내용 | 예시 |
|---|---|
| 문제 단계 | 첫 실행 / Colab 전사 / 두 번째 실행 / Notion |
| 파일 이름 | `0123_1.pdf`, `0123_1.m4a` |
| 작업 폴더 화면 | 어떤 파일이 보이는지 알 수 있는 캡처 |
| 오류 창 | 오류의 첫 줄부터 마지막 줄까지 보이는 전체 캡처 |
