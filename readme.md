# AutoStudy 사용 안내

> **강의록 PDF와 녹음 파일을 넣으면, 전사문·요약 노트·Anki 카드·Notion 정리·복습용 PDF를 만들어 주는 학습 도우미입니다.**

이 문서는 코딩을 하지 않는 사용자를 위한 안내입니다. 처음 한 번만 필요한 설치와 연결 설정은 이미 되어 있다고 가정합니다. 프로그램을 처음 설치하는 경우에는 별도의 **설치 안내**를 따라 하거나, 프로그램을 설정한 사람에게 도움을 요청해 주세요.

이 문서는 "설치하고 실행하는 법"만 다룹니다. 코드 구조, 내부 동작 원리, 알려진 이슈 등 자세한 내용은 [`DEVELOPMENT.md`](./DEVELOPMENT.md)를 참고하세요.

## 이 프로그램으로 무엇을 할 수 있나요?

강의마다 아래 자료가 자동으로 정리됩니다.

| 입력하는 자료 | 만들어지는 결과 |
| --- | --- |
| 강의록 PDF | PDF 내용을 읽은 텍스트와 강의 핵심 키워드 |
| 강의 녹음 파일 | 말한 내용을 글로 옮긴 전사문 |
| 강의록 + 전사문 | 교정된 강의 스크립트, 핵심 요약 노트 |
| 정리된 강의 내용 | Anki 암기 카드와 복습용 PDF |

결과는 Google Drive 폴더와 Notion에서 확인할 수 있습니다.

## 시작하기 전에 확인할 것

매번 시작하기 전에 아래 세 가지만 확인하면 됩니다.

| 확인할 것 | 어떻게 준비하나요? |
| --- | --- |
| 강의록 | PDF 파일을 준비합니다. |
| 녹음 파일 | 가능하면 `.m4a` 파일을 준비합니다. 영상 녹음이라면 `.mp4`도 사용할 수 있습니다. |
| 파일 이름 | 같은 강의의 PDF와 녹음 파일은 **앞 이름을 똑같이** 맞춥니다. |

예를 들어 1월 23일 1교시 강의라면 다음처럼 이름을 맞춥니다.

```
0123_1.pdf
0123_1.m4a
```

> **중요:** `0123_1`이 같아야 프로그램이 “같은 강의의 자료”라고 판단합니다. PDF와 녹음 파일의 앞 이름이 다르면 결과가 만들어지지 않습니다.

## 매 강의마다 하는 일

아래 순서대로 진행하면 됩니다. 보통 **프로그램 실행 → Colab 전사 → 프로그램 다시 실행**의 세 단계입니다.

### 1단계. 강의록과 녹음 파일 넣기

Google Drive 동기화 작업 폴더를 엽니다. 이 폴더를 편의상 **작업 폴더**라고 부르겠습니다.

- 강의록 PDF는 작업 폴더의 `lecture` 폴더에 넣습니다.

- 녹음 파일은 작업 폴더의 **맨 바깥 폴더**에 넣습니다.

- 이미 하나로 합쳐진 강의록 PDF라면, PDF도 작업 폴더의 맨 바깥 폴더에 둘 수 있습니다.

예시는 아래와 같습니다.

```
작업 폴더
├── lecture
│   └── 0123_1_야붙.pdf
│   └── 0123_1_줄.pdf
│   └── 0123_1_야붙필기.pdf #야붙에 직접 필기한 경우
└── 0123_1.m4a
```

### 2단계. 프로그램을 한 번 실행하기

프로그램이 들어 있는 폴더에서 실행 창을 열고 아래 명령을 입력합니다.

```
python main.py
```

이 단계에서는 프로그램이 강의록을 읽고, 음성 전사에 도움이 되는 의학용어 목록을 만듭니다. 잠시 후 작업 폴더에 다음 파일이 생겼는지 확인합니다.

```
0123_1.pdf
0123_1_강의자료.txt
0123_1_whisperkeyword.txt
```

두 파일이 보이면 1차 작업이 끝난 것입니다.

> 실행 창에 오류 문구가 길게 나오거나 프로그램이 바로 종료되면, 직접 고치려 하지 말고 **오류 화면을 캡처**해서 프로그램을 설정한 사람에게 전달하세요.

### 3단계. Colab에서 녹음 파일을 글로 바꾸기

프로젝트의 `colab` 폴더에 있는 **`Transcribe.ipynb`** 파일을 Google Colab에서 엽니다. 위에서 아래 순서대로 실행합니다.

1. Google Drive 연결

1. 필요할 때만 MP4 영상을 M4A 음성 파일로 변환

1. Whisper 설치

1. 음성을 글로 바꾸는 전사 실행

완료되면 작업 폴더에 아래 파일이 생깁니다.

```
0123_1_음성스크립트.txt
```

> **전사가 안 되는 가장 흔한 이유:** 2단계에서 만든 `0123_1_whisperkeyword.txt` 파일이 없기 때문입니다. 이 파일이 보이지 않으면 먼저 프로그램을 다시 한 번 실행해 보세요. 만일 whisperkeyword가 없더라도 전사가 되길 바란다면 Transcribe.ipynb에서 "키워드 없음" 뒤의 continue를 지워주세요.

### 4단계. 프로그램을 다시 실행하기

전사문이 생긴 것을 확인한 뒤, 다시 아래 명령을 실행합니다.

```
python main.py
```

이번에는 프로그램이 강의록과 전사문을 함께 사용해 내용을 교정하고 요약합니다. 처리 시간이 조금 걸릴 수 있습니다.

## 결과 확인하기

처리가 끝나면 작업 폴더에 강의 이름으로 된 새 폴더가 생깁니다. 예를 들어 `0123_1` 강의라면 `0123_1` 폴더가 만들어집니다.

| 결과물 | 어디에서 보나요? | 무엇인가요? |
| --- | --- | --- |
| 교정된 강의 스크립트 | `0123_1` 폴더의 `0123_1_최종교정본.txt` | 녹음 내용을 강의록에 맞춰 다듬은 글 |
| 핵심 요약 | Notion 페이지 | 시험 대비용으로 정리한 노트 |
| Anki 카드 | `0123_1` 폴더의 `0123_1_통합본.apkg` | Anki 앱으로 열어 복습하는 암기 카드 묶음 |
| 복습용 PDF | `0123_1` 폴더의 `0123_1_scripted.pdf` | 슬라이드와 교정 스크립트를 함께 볼 수 있는 PDF |

Anki를 사용할 때는 `0123_1_통합본.apkg` 파일을 Anki 앱에서 열거나 가져오면 됩니다. Notion에는 요약, 슬라이드별 스크립트, Anki 파일 링크가 순서대로 올라갑니다.

## 하루치 복습 PDF 한 파일로 만들기

같은 날짜의 강의를 모두 처리했다면, 복습용 PDF를 하나로 합칠 수 있습니다.

먼저 작업 폴더 안에 `merged`라는 폴더가 있는지 확인합니다. 없다면 새 폴더를 만들고 이름을 정확히 `merged`로 지정하세요.

그다음 프로그램 폴더에서 아래 명령을 실행합니다.

```
python utility/merge_pdf.py
```

화면에 날짜를 입력하라는 안내가 나오면 `0123`처럼 네 자리 날짜를 입력합니다. 같은 날짜의 `0123_1`, `0123_2` 강의가 순서대로 합쳐져 아래 위치에 저장됩니다.

```
작업 폴더\merged\0123_merged_scripted.pdf
```

## 자주 생기는 문제

| 상황 | 먼저 해 볼 일 |
| --- | --- |
| 전사문이 만들어지지 않아요. | `*_whisperkeyword.txt` 파일이 있는지 확인하고, Colab에서 올바른 Google Drive 폴더를 보고 있는지 확인합니다. |
| 최종 요약·Anki·PDF가 만들어지지 않아요. | PDF, 녹음 파일, `*_강의자료.txt`, `*_음성스크립트.txt`의 앞 이름이 모두 같은지 확인한 후 프로그램을 다시 실행합니다. |
| Notion에 결과가 없어요. | Google Drive와 Notion 연결 설정이 되어 있는지 확인합니다. 오류 화면을 캡처해 전달하는 것이 가장 빠릅니다. |
| 날짜별 합본이 안 만들어져요. | 모든 강의 폴더에 `*_scripted.pdf`가 있는지, `merged` 폴더가 있는지 확인합니다. |
| 엉뚱한 파일이 같이 이동했어요. | `0123_1`과 `0123_10`처럼 앞 이름이 겹치는 강의를 작업 폴더에 동시에 두지 마세요. 한 강의씩 처리하는 편이 안전합니다. |

## 꼭 기억할 세 가지

> 1. **같은 강의의 PDF와 녹음 파일은 앞 이름을 똑같이 맞춥니다.**
1. **프로그램은 한 번 실행하고, Colab 전사 후에 다시 한 번 실행합니다.**
1. **결과가 안 나오면 파일을 바로 지우지 말고, 화면과 폴더 상태를 캡처합니다.**

## 도움이 필요할 때 전달할 정보

문제가 생기면 아래 네 가지를 함께 전달하면 해결이 훨씬 빨라집니다.

1. 실행 화면에 나온 오류 문구의 전체 캡처

1. 작업 폴더 안에 보이는 파일 목록 캡처

1. 처리하려던 강의의 PDF와 녹음 파일 이름

1. 문제가 생긴 단계: 1차 실행, Colab 전사, 2차 실행, Notion 또는 Anki 중 어디인지
